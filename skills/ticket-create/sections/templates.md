# チケット種別別テンプレート

## Bug

エラー・障害・テスト失敗の修正は、深い分析前に親を立てる。手順は `bug-flow.md`。

```
## 現象
...

## 再現手順（分かっている範囲で可。起票後に確認子で固める）
1. ...

## 期待値
...

## 実際
...

## 環境
- OS: ...
- バージョン: ...

## 範囲
- 現象確認 → 調査 → 解決（親はハブ。作業は子）

## 完了条件（親）
- [ ] 現象が解消したことを確認子／解決子の検証で示せる
- [ ] 子（確認・調査・解決）が Resolved

## 分割候補
- 現象確認
- 調査
- 解決
```
