# 更新可能なフィールド

| フィールド | 説明 |
|---|---|
| `status_id` | ステータス |
| `priority_id` | 優先度 |
| `assigned_to_id` | 担当者 |
| `category_id` | カテゴリ |
| `due_date` | 期限（カレンダー。ブースト計算には使わない） |
| `start_date` | 開始日 |
| `estimated_hours` | 人手想定の予定工数（人時）。エージェント前提で短くしない |
| `done_ratio` | 進捗率 |
| `custom_fields` | カスタムフィールド |
| `notes` | ジャーナルコメント |
| `description` | 説明 |
