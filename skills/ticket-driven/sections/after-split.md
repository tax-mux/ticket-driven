# 分割後の作業順

1. 依存なし（先行）の子から着手する（粗い子のまま着手しない）
2. **親には着手ジャーナルも In Progress も付けない**（ハブ専用）
3. 子の着手前に `ticket-refine`（**漏れ拾い**。split が充足していれば更新スキップ）
4. 子のテスト範囲は子の完了条件に対応させる（親の計画をコピーしない）
5. 子の着手ノートに **委任パック**を書く（`delegate-pack.md`。欠落なら edit しない）
6. 子を Resolved する前に **クローズ監査**（`close-audit.md`）
7. 子を Resolved にするたびに親の `done_ratio` を更新する
8. すべての子が Resolved になったら親を Resolved にする（親もクローズ監査＋完了ノート）

**再開時**: 親や粗い子の「続き」に入らず、未完了の細かい子を選び直す。サイズが怪しい／親のまま実装していたなら先に再分割（`resume.md`）。

粗い子の再分割は `ticket-split` の再分割手順に従う。
