# 委任パック（着手前必須）

子（または `分割不要:` の単一票）に着手する直前に、**ジャーナルへ1回**書く。チャットだけの把握は不可。人が親だけ見て委任できるようにする。

## 必須フィールド（すべて1ノートに含める）

| 項目 | 内容 |
|------|------|
| 作業単位 | `#{実装チケットID}`（子があるなら子。親ハブは不可） |
| DoD | この票の完了条件を短く列挙（description と一致） |
| 影響範囲 | 中心パス／成果（この票だけ） |
| 検証 | テスト範囲に対応する **1系統**（コマンドまたは確認手順） |
| 依存 | 先行チケット／外部待ち。無ければ `なし` |
| 禁止 | 親への実装・親 In Progress・他子へのスコープ侵食・委任範囲外のメタ作業 |

## 着手ノート形式

```
着手: {概要1行}

委任パック:
- 作業単位: #{id}
- DoD: {項目を読点または箇条}
- 影響範囲: {中心パス／成果}
- 検証: {1系統}
- 依存: {なし|#{id}…}
- 禁止: 親実装 / 他子侵食 / 範囲外メタ
```

`着手:` だけのノートは **不足**。委任パック欠落のまま edit しない。

## 作業中の境界

- 触ってよいのは委任パックの影響範囲に書いた中心だけ
- DoD 外の発見は親または新子へ回す（当該票に勝手に足して Resolved しない）
- 合格ライン割れ・必須トリガ A–F 相当に膨張したら、実装継続より先に再分割（`resume.md` / `ticket-split`）
