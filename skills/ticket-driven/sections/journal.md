# ジャーナル・タイミング

| タイミング | ジャーナル |
|-----------|------------|
| 精緻化（自動時） | `精緻化: {要約}`（refine 側。充足済みなら「更新なし」） |
| 分割（子を作った） | `分割: 機能構成→セッション完走` + 子 ID と題名の箇条書き（必須） |
| 分割不要（子を作らない） | `分割不要: {理由}`（**省略禁止**。下記フォーマット） |
| 再開検討（把握・サイズ判定の直後） | `再開検討: 残りDoD={n} / 判定={分割\|#子…\|分割不要} / 作業単位=#{id}`（実装前。詳細は `resume.md`） |
| 着手 | `着手: {概要}` ＋ **委任パック**（形式は `delegate-pack.md`。実装チケット＝**子優先**。子がある親には書かない） |
| テスト計画 | `テスト計画: {要約}`（新規作成・大幅補完時のみ） |
| テスト実行 | 完了ノートに含めてよい（`完了: ... — テスト: {結果}`） |
| リファクタ（予防） | `リファクタ: 予防 — {要約}`（大きめの分割・浅化時のみ） |
| リファクタ検討 | `リファクタ検討: {実施|見送り} — {要約}`（しきい値超過時のみ） |
| 完了 | `完了: {概要} — {検証結果}` |

進捗ジャーナルの連投は不要。詰まったときだけ追記。

## 分割証拠（HARD GATE 用）

着手前に、対象チケット（分割した場合は親）のジャーナルに次のいずれかが **実在**すること。チャット上の「判定した」だけでは不可。

### `分割:`（子を作ったとき）

```
分割: 機能構成→セッション完走
- #{子1}: {タイトル1}
- #{子2}: {タイトル2}
作業単位は子。親はハブ。
```

### `分割不要:`（子を作らないとき・省略禁止）

1行で次をすべて含める:

```
分割不要: DoD={n}個 / 中心ファイル目安={少数|1成果} / 理由={1セッションで着手〜Resolvedまで収まる根拠}
```

**禁止**: 機械的必須分割（`ticket-split` の policy: 必須トリガ A–F。DoD≥4 / 独立塊≥2 / 中心成果≥2 / 中心パス≥4 / 同居禁止 等。事前に数える指標のみ）に該当する親で `分割不要:` を書くこと。該当なら子を作れ。

**禁止**: `分割不要: 単一まとまり` のような理由なし／短い言い逃れ。

## 委任パック（着手時）

`着手:` ノートには `delegate-pack.md` の6項目を含める。欠落した着手は HARD GATE 未充足（実装に入らない）。

## 完了ノートとクローズ監査

`完了:` の前に `close-audit.md` を満たす。形式:

```
完了: {概要} — テスト: {結果}
クローズ監査: DoD全[x]=yes / 検証一致=yes / 親実装なし=yes / 範囲内=yes
```

監査が no の項目があるうちは **Resolved にしない**。
