# 子チケットのサブエージェント委任（共通）

親セッションをハブにし、**実装は子 1 枚をサブエージェントへ渡す**。呼び出し口（ツール名・引数）はランタイム別ファイルだけに書く。

## 前提（この環境）

- ローカル LLM は **同時に 1 プロセス**（1 エンドポイント）が基本
- そのため **子チケットの並列委任・並列実装は禁止**
- 子は **1 枚ずつ**。前の子が Resolved（または明示的に停止）してから次へ

## いつ使うか

| 使う | 使わない |
|------|----------|
| 親で refine + split 済み、子 ID が確定している | 分割証拠が無い |
| 委任パックを子へ渡せる | 親ハブに実装しようとしている |
| OpenCode / Hermes でサブエージェントが使える | Cursor 対話のみ（**新チャット推奨**。本節は任意） |
| 子が 1〜数枚で、親に結果要約だけ戻したい | 子が多く親が太る → **新セッション**へフォールバック |

## 役割分担

| 役割 | やること | やらないこと |
|------|----------|--------------|
| 親（ハブ） | refine / split / `分割:` / 次子の選定 / done_ratio / 全子後の親 Resolved | 実装・親 In Progress・複数子の同時委任 |
| 子（サブエージェント） | 委任パックに従い着手〜検証〜Resolved | 他子・親へのスコープ侵食・追加の並列委任 |

## 必須順

```
1. 親で ticket-refine → ticket-split（分割証拠あり）
2. 依存なしの未完了子を 1 枚選ぶ
3. 子に委任パックを書く（Redmine ジャーナル。delegate-pack.md）
4. ランタイム固有ファイルに従い、その子だけをサブエージェントへ委任（直列）
5. 子が Resolved するまで次の子を起動しない
6. 親の done_ratio 更新 → 次の子へ（2 へ）
7. 全子 Resolved 後、親をクローズ監査 → Resolved
```

## 子へ渡す内容（共通・必須）

サブエージェントは **親の会話履歴を見ない**。次をすべて `prompt` / `goal`+`context` に含める。

- 作業単位 `#{子ID}`、親 ID（触らない旨）
- 委任パック 6 項目（DoD / 影響範囲 / 検証 / 依存 / 禁止）
- Redmine: **Tier 1 get**（description）。journals は必要なときだけ
- 完了まで: 着手（パック済みなら再掲可）→ 実装 → テスト → クローズ監査 → Resolved
- **並列禁止**・他子・親への編集禁止

## 禁止

- **2 枚以上の子を同時にサブエージェント起動する**
- 読取専用でも、同一 LLM プロセス上での並列委任
- 親セッション内で子の実装を自分で進める（委任するなら任せ切る）
- 委任パックなし / DoD なしでの委任
- ランタイム固有のツール例を本ファイルに書くこと

## フォールバック

次のいずれかならサブエージェントせず、**新セッション**（または手動で子だけ着手）にする。

- サブエージェントが失敗・権限不足・MCP 非継承
- 親コンテキストが既に太い
- ユーザーが新セッションを指定

## ランタイム別（呼び出し口のみ）

| ランタイム | 読むファイル |
|------------|----------------|

| Hermes | `delegate-subagent-hermes.md` |
