# チケット精緻化 (Ticket Refinement)

Redmine チケットの内容を精緻化し、開発可能な状態に整える。

## 目的

- 曖昧な要件を具体的なものにする
- 欠落している情報を補完する
- 実装可能な粒度に分解する
- 完了条件を明確にする

## ワークフロー

### 0. リモートリポジトリの確保

チケットの内容を確認する前に、必ずリモートリポジトリが確保されているか確認する。

- リモートリポジトリが未作成の場合:
  1. チケットのコメントに「リポジトリ未作成」を登録
  2. チケットを保留（フィードバック等）にする
  3. リポジトリ作成後に再開

- リモートリポジトリ確認方法:
  ```
  git remote -v
  ```

### 1. 現状分析

```json
{
  "action": "get",
  "issue_id": "{ID}",
  "include": ["journals"]
}
```
ツール: `redmine_issues`

以下の項目をチェック:

| 項目 | 確認点 |
|---|---|
| 概要 | 何がどうなるべきか明確か |
| 説明 | 背景・文脈が十分か |
| 完了条件 | 検証可能な条件が列挙されているか |
| 実装方針 | 具体的な方法が示されているか |
| 影響範囲 | 関連するファイル・機能が明記されているか |
| 注意事項 | 留意すべき点があるか |

### 2. 質問リストの生成

以下の観点から不足情報を特定:

**機能面**
- 入力データは何か？形式は？
- 出力結果は何か？フォーマットは？
- エッジケースは何か？
- 成功/失敗の定義は？

**技術面**
- 既存コードとの連携は？
- 依存ライブラリは？
- DB スキーマ変更が必要か？
- API 変更・新增が必要か？

**品質面**
- テストは必要か？
- パフォーマンス要件は？
- セキュリティ要件は？
- ログ出力は？

### 3. 精緻化提案

以下のテンプレートで再構成:

```
## 背景
（現在の状況と問題点）

## 目的
（このチケットで達成すること）

## 要件
### 機能要件
- [ ] 要件1
- [ ] 要件2

### 非機能要件
- パフォーマンス: ...
- セキュリティ: ...

## 実装方針
1. 手順1
2. 手順2

## 完了条件
- [ ] 条件1
- [ ] 条件2

## 影響範囲
- 変更: path/to/file
- 参照: path/to/file

## 注意事項
- 留意点1
- 留意点2

## 検証手順
1. ...
2. ...
```

### 4. チケット更新

精緻化後、チケットに反映:

```json
{
  "action": "update",
  "issue_id": "{ID}",
  "issue": { "description": "{精緻化内容}" }
}
```
ツール: `redmine_issues`

ジャーナルにコメント追加:

```json
{
  "action": "add_note",
  "issue_id": "{ID}",
  "notes": "チケットを精緻化: {要約}"
}
```

## 精緻化チェックリスト

- [ ] 背景・目的が明確
- [ ] 機能要件が列挙済み
- [ ] 完了条件が検証可能
- [ ] 実装方針が具体化
- [ ] 影響範囲が特定
- [ ] エッジケースが考慮
- [ ] 依存関係が明確
- [ ] テスト方針が決定

## 例

### 精緻化前

```
ユーザー一覧を表示したい
```

### 精緻化後

```
## 背景
現在、管理者はユーザー情報を一元管理できないため、
運用負荷が高まっている。

## 目的
管理者画面にユーザー一覧ページを実装し、
ユーザー情報の参照・検索・フィルタリングを可能にする。

## 要件
### 機能要件
- [ ] ユーザー一覧をテーブル形式で表示
- [ ] 名前・メールアドレスでの検索
- [ ] 役職でのフィルタリング
- [ ] ページネーション（1ページ50件）
- [ ] 名前順デフォルトソート

### 非機能要件
- 読み込み時間: 2秒以内（1000件時）

## 完了条件
- [ ] 1000件のユーザーが表示可能
- [ ] 検索・フィルタが正常動作
- [ ] ページネーション動作確認

## 影響範囲
- 新規: app/views/admin/users/index.html
- 新規: app/controllers/admin/users_controller.rb
- 変更: app/models/user.rb（スコープ追加）
```
